# 第2版独立网站

此目录是一个完整、独立的 GitHub 仓库。资料、上传文件、CMS 配置和发布流程均使用本仓库文件，不依赖另一版在线网站。

第一版沿用原仓库；第二版需要新的公开仓库。GitHub Pages 的 Source 选择 GitHub Actions。
使用 Pages CMS 登录同一个账号后，选择对应仓库维护；两版不会自动同步。
请将本目录内容（包括 .pages.yml 和 .github）放在仓库根目录，不要额外套文件夹。
第一版源码的模板与共用构建工具在第二版中保留作兼容测试用途；第二版发布流程只发布团队网站。
拆分不增加同一账号的 Actions 共享存储额度。每次临时发布包保留一天。
